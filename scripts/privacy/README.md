# 隐私扫描器来源

`scan_secrets.py` 来自用户指定的 `security` 技能，按该技能声明的 MIT 许可证保留副本。项目入口为 `scripts/check-privacy.py`。

原扫描器保持原样；包装入口只扫描明确的 Git 公开文件或指定的构建暂存目录，补充 HTML/CJS 和个人路径检查。中、高风险均会阻止检查通过。测试夹具误报仅可按文件、规则和原始行的 SHA256 精确登记，必须注明人工复核原因；不得对整个测试目录放行。

包装入口同时覆盖 JSON 引号键、UTF-16 BOM 文本，并要求公开 Python 配置仅为 `{}` 空模板。`--staged` 连同扫描策略及误报清单一起读取 Git 索引，未暂存的策略修改不能放行本次提交。第三方许可证中的公开署名和示例联系方式应人工区分，不删除必需的许可证信息。

扫描输出只包含规则、文件和行号，不输出命中值或代码片段。完整原始本机报告不得提交或作为 Actions 产物上传。
