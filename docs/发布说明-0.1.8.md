# 三人聚智 0.1.8 正式版

本版纳入更新检查、账号同步及旧版数据导入修复，沿用独立的应用身份和用户数据目录。原效率工具、原 Python 程序管理及现有配置继续保留。

## 主要变化

- 检查更新使用 `yuhanbo758/sanrenjz` 的正式 Latest，与商店会员权限独立。按系统及架构选择包，下载支持取消与重试，完成下载及打开安装前均验证大小和 SHA256。检查不会自动下载或安装。
- 程序小店使用同一内置商店分区的 HttpOnly Cookie 会话查询账号，兼容旧 Bearer。两类会员权限分别查询；服务错误显示待确认，退出登录阻止在途请求和旧页面恢复账号。
- 设置新增“数据导入”，分别检测原效率工具及原 Python 程序管理，支持手选安装、便携、插件和用户数据目录。先预览、备份，只补缺少插件、配置与插件偏好，已有数据保留，冲突列入报告。旧解释器为可选项，现有环境选择优先。
- 同名 Python 程序已内置时，仍可按稳定配置 ID 补入缺少的旧配置。保留 `.enc` 和嵌套数据库，拒绝配置越界及链接目录，排除 Python 环境。导入不运行业务任务，不启用旧自启动，不复制登录凭据。

## 发布范围

Actions 在 Windows x64、macOS Intel x64、macOS Apple Silicon arm64、Linux x64 的原生 runner 分别构建并隔离验收。四个目标及隐私门禁全部通过后才发布正常 Release 并设为 Latest；版本由维护者明确更新，不覆盖既有公开标签和资产。

公开资产为 Windows EXE、两种 macOS 架构各自的 DMG/ZIP、Linux AppImage/tar.gz，以及 `SHA256SUMS.txt`、`release-manifest.json`。来源清单记录每个平台、架构、实际包哈希和原生验收结果，具体结果以对应 Actions 和来源提交为准。

默认公开包只包含40个效率插件及4个 Python 插件，排除私有插件、真实配置、登录令牌、Cookie、日志、迁移备份和 Python 运行时。Windows 包未使用正式代码签名；macOS 采用 ad-hoc 签名且未公证，不能等同于 Developer ID 签名发行。
