## 修复

1. 快捷键录入改为主进程会话。已有全局组合键在录入期间只回传按键，不打开搜索、钉住窗口或唤起超级面板。录入临时注册 Alt+Space，补充可点击预设，取消/失焦恢复原值，按键释放前抑制重复消息。
2. 注册成功后才保存；失败恢复旧绑定和设置。成功修改后释放旧组合键。启动不强制覆盖用户选择；修改搜索关键词不再重注册快捷键。超级面板快捷键可以清除。
3. Windows 启动器和主进程初始化显式设置当前宿主控制台 UTF-8，并原生回读确认；不转换或替换中文源码，不盲目解码未知 GBK 字节流。

## 使用

从托盘退出当前旧进程后，重新运行 `npm start` 或使用 0.1.1 安装包。设置 → 快捷键 → 点击 Alt+Space → 保存设置；也支持点击修改后按 Alt+空格录入。

日志修复对重新启动后的新输出生效，终端中已有的旧乱码不会被回写。
