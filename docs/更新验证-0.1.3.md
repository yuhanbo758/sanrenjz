# 0.1.3 设置体验优化与快捷搜索排序修复

日期：2026-11-03。交付为本地 Windows x64 预览版，未提交、配置远端、推送或发布。两个来源项目保持原样。

## 用户可见变化

### 设置界面

- 设置窗口增加统一标题、说明和分类导航，内容区独立滚动、页脚固定。统一字体、卡片、按钮、状态徽章与路径换行，在窄窗口中调整布局。
- Python 环境按当前解释器、添加环境、电脑候选、诊断和插件维护分组。已保存路径显示“待诊断”，主动验证后才显示验证状态；仅浏览设置不扫描或安装 Python。
- 候选显示版本、架构、pip/Tk 状态，并标记当前环境，避免重复选择。检查有加载、失败、空结果和重试反馈。
- 环境操作串行，安装期间禁止切换、诊断或重复安装，保留进度和取消入口。取消和失败后停止进度显示，保留原选择。
- 插件与环境操作即时保存；没有待保存应用偏好时，页脚为“完成”。常规、快捷键和超级面板设置仍通过“保存设置”生效。切页保留输入，有待保存项时保留保存入口，关闭时可取消放弃修改。
- 保存成功和失败改为非阻塞通知；通知内容按文本渲染。分类导航支持方向键及 Home/End。

### Python 插件配置目录

- 配置目录放在常规设置，显示实际路径，支持更改、打开和恢复默认，独立即时保存，无需 Python。
- 复制缺少配置并保留目标已有文件；同步兼容的两项旧设置键，保证宿主和标准 VBS 的目录解析一致。正在运行或启动 Python 插件时拒绝切换目录。
- 目录校验包括两类插件程序目录、真实路径/联接和 Git 跟踪目录保护。复制或设置落盘失败不更换选择；落盘后的刷新异常仅提示警告。

### 快捷搜索

- 排序优先级为：不同查询词覆盖数 → 插件、命令、片段类型 → 相关性。
- `skill gitea`：2/2 的备份片段排在只匹配 1/2 的视频插件之前。单词 `skill`：相同覆盖下仍优先插件。
- 重复查询词去重，统一大小写与空白；片段跨标题、正文和预览的匹配按并集合计。直接搜索与逐字输入共用同一评分函数。
