## 采纳的业务改动

1. **效率插件的 macOS 独立 Dock 图标**：钉住和自动分离时创建稳定的独立应用身份；激活 Dock 图标可恢复并聚焦对应窗口。取消钉住、关闭插件和退出宿主时清理辅助进程；原窗口及业务继续由宿主管理。
2. **Python 插件图标跨平台适配**：Mac/Linux 优先 PNG，缺少时回退宿主图标；Windows 保持 ICO 策略。Mac 对仅 ICO/ICNS 的插件通过原生图像接口设置 Dock 图标，启动和导入不生成图片、不安装依赖。
3. **Python 导入路径纠正**：导入结果和运行入口使用物理路径匹配，处理 Mac `/var` 与 `/private/var` 别名，保留稳定条目 ID。
4. **构建与验收**：新增当前原生 Mac 架构的 Dock 辅助程序编译、ad-hoc 签名和随包资源；补充安装包资源、执行权限、架构及真实钉住/退出验收。本地打包仅接受显式 `--publish never`。
5. **显式图标制作工具**：新增 `scripts/prepare-python-plugin-icons.py`，默认只检查，`--apply` 仅补齐缺少的 PNG，保留原 ICO、PNG、清单和配置。

项目的 Git 操作由外部工具维护，不在业务源码中引入本机操作适配。
