## 问题与修复

原“设置 → 插件管理”调用的管理目录只返回效率插件；Python 管理列表位于“Python 环境”底部，未进入同一个管理页。

- 管理目录改为聚合效率工具和 Python 完整列表，包括隐藏插件。增加“全部插件 / 效率工具 / py程序”类型筛选、类型标签、共同搜索及两类统计。
- 对照原 Python 管理设置，保留“随主程序启动”和“在主界面显示”，使用稳定条目 ID 保存，跨类型同名互不串写。默认显示、不自启动；勾选立即保存，自启动在下次启动宿主时生效。
- 效率插件原有关键词、窗口分离、后台退出、搜索推送与超级面板选项继续保留；Python 行只提供适用选项，展开后可查看入口、说明、运行日志或移除。移除保留用户配置，运行中禁止移除。
- Python 环境页移除重复管理表格，保留解释器、诊断、配置目录等功能，并提供跳到统一管理页的入口。
- 导入、移除、偏好变更同步刷新主页面和管理列表，隐藏项可恢复，类型筛选与展开状态保留。
- 落盘失败时开关恢复原值；落盘成功后刷新失败仅提示刷新警告，避免误报保存失败。直接打开 Python 设置时初始化通用设置，在已打开模态框内切换时保留未保存输入。
