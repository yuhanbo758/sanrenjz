# 公开范围与隐私检查

提交前运行 `npm run audit:privacy` 和 `npm run audit:public`。前者读取 Git 公开候选，后者核对私有插件忽略和公开 Python 清单。暂存后再运行 `python scripts/check-privacy.py --staged`，按实际索引中的源码和策略检查本次提交。

隐私扫描覆盖 HTML/CJS、JSON 凭据字段、UTF-16 BOM 文本和本机用户目录；公开 Python 配置只允许 `{}` 空模板。测试夹具、校验串及固定认证前缀等误报，须人工复核后在 `config/privacy-allowlist.json` 逐项记录文件、规则、行 SHA256 和原因。修改该行后必须重新复核，不能对整个目录放行。

GitHub Actions 先扫描公开源码，构建后再扫描唯一公开暂存目录，通过后才允许收集安装包。默认包始终采用 40 个效率插件和 4 个 Python 插件的公开清单，不收录本机私有插件、真实配置或 Python 运行时。

`.gitignore` 的排除不能消除本机源码中可能存在的凭据风险。若扫描发现疑似真实凭据，应先提示并更换或撤销授权，再按用户授权继续发布；不得尝试使用扫描到的凭据验证有效性。完整扫描报告可能含敏感片段，只保留在忽略目录，不能上传为构建产物。

第三方许可证中的公开作者署名、邮件地址，以及明确的测试示例，不应作为个人资料直接删除。自动扫描是格式与范围检查，不能保证识别所有自定义凭据格式；发布前仍应人工检查新增配置与资源。
