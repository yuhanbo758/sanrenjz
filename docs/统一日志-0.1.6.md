# 0.1.6 统一运行日志

日期：2026-11-04。当前项目本地修改，未提交、推送或发布，来源项目保持原样。

## 用户可见变化

- 顶部“日志”在效率工具和 py程序页面始终显示，默认查看全部类型；Python 环境入口仍只在 py程序页显示。
- 同一窗口查看效率插件和 Python 程序日志，支持“全部类型 / 效率工具 / py程序”和具体插件两级筛选。同名程序按带类型的稳定 ID 区分。
- 支持实时追加、刷新和导出当前筛选；隐藏程序及本次缓存仍有记录的已移除来源继续可筛选。缺失目标仍保留筛选并显示空结果，避免意外扩大导出范围。
- Python 卡片和设置入口沿用同一窗口，并预选对应类型或程序；旧 Python 日志 IPC 保持兼容。
- 当前会话默认最多保留 4,000 条、单条 16,000 字符、总字符预算约 200 万；超过限制淘汰最早记录。界面在超长情况下只显示末尾部分并提示，导出包含缓存内全部匹配记录。没有新增日志落盘或用户配置迁移。

## 采集与数据保护

效率插件采集主窗口和指示器窗口的控制台、加载失败、渲染退出及生命周期；JS 插件接入 IPC 输出、连续 UTF-8 stdout/stderr、启动错误、退出及主动停止。复用窗口不会重复注册采集。

Python 通过既有日志回调进入统一缓存。统一记录含序号、类型、稳定 ID、名称、时间、通道和文字。按常见敏感字段脱敏，过滤宿主存储调试值及已知框架/标题栏噪音，保留程序自身警告和错误。日志通知失败不影响插件运行。

仅查看、筛选和导出日志不检查或安装 Python，不启动插件业务，不写设置。前后校验 2,494 个现有配置文件，全部未变。
