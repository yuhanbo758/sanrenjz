# 三人聚智 0.1.9 正式版

本版包含客户端头像与旧插件程序导入修复。版本按正式通道发布，只有 Windows x64、macOS Intel、macOS Apple Silicon、Linux x64 四个原生目标的构建、隐私检查和隔离运行验收全部通过，才公开 Release 并设为 Latest。

## 客户端头像

- 未设置头像时，无论是否登录均显示程序 logo，修复安装态资源路径及重启后恢复默认图的问题。
- 点击右上角头像可选择 PNG/JPG 图片或恢复默认。支持最大 5 MB、1600 万像素，转换为最长边不超过 512 的 PNG，去除附带文本和 EXIF 等信息。
- 自定义图片仅保存在本机，重启后保留，登录或退出不覆盖选择，不上传商店。取消、无效图片和保存失败均保留原头像。
- 文件以独立目录、摘要命名和原子切换保存，恢复默认只清理受管文件；目录链接检查和公开范围检查防止误删或误打包本地图片。

## 旧插件程序导入

- 修复目录名为 sanrenjz-tools 或 yuhanbopy-app 时被误认作纯配置来源、插件数显示为 0 的问题。
- “设置 → 数据导入 → 选择插件所在目录”支持旧安装/便携目录、plugins、resources/app、单插件文件夹及插件集合。
- 预览展示识别的程序目录、数量与插件清单。可以分别选择导入程序、配置和偏好；仅有配置的来源会提示选择仍保留程序文件的位置。
- 支持用户自行安装的非开源插件，并保留插件自带的依赖资源；不以公开发行白名单过滤用户本地迁移。
- 先备份，再补充缺少项。同名插件、已有配置和原项目保留；导入后刷新主列表、管理列表和搜索目录，不运行插件、安装依赖或启用旧自启动。

## 交付与数据保护

公开安装包继续只包含允许清单中的 40 个效率插件和 4 个 Python 插件，排除本地私有插件、用户头像、真实配置、登录数据及 Python 运行时。Python 程序仍使用用户选择的解释器；旧 Python 环境不整套迁入。

四个构建目标交付 Windows EXE、两种架构各自的 macOS DMG/ZIP、Linux AppImage/tar.gz，以及 release-manifest.json、SHA256SUMS.txt。Windows 无代码签名；macOS 为 ad-hoc 签名、未公证，正式版本通道不代表 Developer ID 签名。

本地已用临时配置和合成插件验证选图、重启、恢复默认、程序复制、依赖资源、冲突保护及目录刷新；未代用户执行真实私有插件业务。CI 会重新执行本版逻辑及 Windows 界面回归，并对每个平台实际打包程序进行隔离运行检查。具体构建和下载结果以对应 Actions 与 Release 来源提交为准；隔离测试不能替代用户设备上的覆盖安装、权限和私有业务验收。
