## 发现并修复的问题

### Python 生命周期与日志

1. 逐块 `toString('utf8')` 会损坏跨块的中文/emoji，也会漏掉分块敏感字段。改为连续 UTF-8 解码、完整行脱敏、无换行尾部刷新与长行内存限制。
2. 运行、退出时异步刷新/日志通知失败会形成未处理拒绝。改为独立捕获通知失败，保留系统提示，不破坏管理器的启动、停止和退出。
3. 新增真实 Python 父子进程停止与关闭后拒绝再次运行的验证。VBS 测试现在等待程序与独立启动器都退出，再异步清理临时目录，修复原测试的 Windows 清理竞态。

涉及：`app/python-manager.js`；`tests/python-manager-regression.test.js`、`tests/python-manager.test.js`。

### 快捷搜索与执行结果

1. 中文输入法组词时回车/方向键可能执行旧结果；组合输入开始也未清理待渲染搜索。现在组合阶段不执行或移动结果。
2. 快速输入后立即回车、或在重绘前点击旧行，可能打开错误插件。现在先同步最新查询再执行，长按回车不重复启动。
3. 钉住后 Esc 被普通失焦隐藏逻辑拦截。现在显式 Esc 可关闭，失焦继续保持钉住。
4. 底层功能失败被多层调用吞掉，仍被当成启动成功。`PluginManager.runPlugin`、旧运行 IPC 和统一运行 IPC 现在透传失败，界面显示原因并保留搜索窗口。
5. 文本片段派发失败显示文本通知；目录刷新和再次获得焦点会补查目录，加载失败明确提示。多词覆盖优先的排序规则继续通过回归。

涉及：`search-window.html`、`main.js`、`app/merged-host.js`、`app/software_manager.js`；新增 `tests/merged-search-actions*.js/cjs`。

### 设置保存与原配置保留

1. 初次读取未完成时能提交空字段或旧值。现在合并读取请求、锁定读取期间的通用控件，关闭后旧响应失效。
2. 保存响应到达时把新输入错误标记为已保存并关闭。现在只确认提交快照，响应期间的新修改继续保留。
3. 管理列表持有整份陈旧关键词设置，可能覆盖其他插件的更新。新增 `set-plugin-search-keywords` 窄 IPC，仅原子更新目标插件，保留 enabled、其他插件与附加字段；通用保存只发送自身字段。
4. 关键词保存失败、列表刷新或直接 Esc 可能丢失草稿。现在输入时保留草稿，失焦即时保存，失败可重试；确认放弃后不再由隐藏页面写回。
5. 普通保存会重复设置系统自启动或重新注册未改变的快捷键。现在仅处理需要改变或已失效的绑定；失效快捷键可按原保存值重试。
6. 系统自启动错误发生在落盘之后会产生假失败。现在系统自启动和落盘失败时恢复旧状态，并与快捷键事务共同回滚；启动时系统设置失败仅提示，不退出应用。
7. 损坏或非对象设置原先可能被默认值覆盖。现在严格阻止写入并保留原字节，便于修复与恢复。

涉及：`index.html`、`merged-ui.js`、`main.js`；新增两进程持久化及保存副作用验收。
