# 共享 AI 当前模型搜索

日期：2026-11-08。

## 使用方式

点击插件顶部的“当前模型”或“视觉模型”选框，在展开面板中输入模型显示名称、模型 ID 或供应商名称。支持忽略大小写及空格分隔的多个关键词；结果按供应商分组，同时显示模型名称和 ID。

鼠标点击结果即可切换，也可用方向键移动候选、回车确认。Esc、Tab 或点击面板外部关闭搜索。输入、过滤和取消搜索不改变当前选择，只有明确选择且设置保存成功后才切换模型。

## 修改范围

- `app/plugin_runtime/ai-provider-manager.js`：将顶部原生下拉框替换为带搜索的共享弹出选择器；底层选择状态和供应商配置接口保持兼容。
- 选择器按各插件要求的 text/vision 能力过滤，兼容 OpenCode 及自定义供应商；同名模型以供应商和模型 ID 区分。
- 搜索使用本地配置，不调用供应商目录或模型接口，不读写密钥。
- 输入法组合输入、重复确认及搜索框按键不会触发插件页面快捷操作。保存期间阻止重复切换；保存失败保留原模型并显示错误。
- 搜索浮层挂在页面顶层，按窗口大小定位，列表独立滚动；新 UI 使用既有主题变量，没有新依赖。
